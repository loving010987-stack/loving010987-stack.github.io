수업 의도

같은 타일이라도 어떻게 이동하느냐에 따라 무늬가 달라진다는 것을 직접 만들어 보며 느끼게 합니다. 버튼을 누르기 전에 결과를 예상하고, 만든 뒤 확인하는 과정이 핵심이에요.

수업 흐름

  1. 도입 실제 포장지·벽지 무늬를 보며 반복되는 모양과 방향 찾기
  2. 활동 타일 그리기 → 이동 방법 예상하기 → 만들어서 확인하기 → 같은 타일로 다른 방법 비교하기
  3. 정리 친구 포장지를 보고 어떤 방법으로 이동했는지 맞혀 보기

발문 예시

  • "버튼을 누르기 전에, 어떤 무늬가 나올지 먼저 말해 볼까?"
  • "좌우 뒤집기와 위아래 뒤집기는 무늬가 어떻게 다르니?"
  • "오른쪽으로 뒤집고, 다시 아래쪽으로 뒤집으면 몇 도 돌린 것과 같을까?"

활용 팁

  • 한쪽으로 치우친 그림을 그려야 차이가 잘 보여요. 좌우가 똑같은 그림은 좌우로 뒤집어도 똑같거든요.
  • 회원가입·로그인 없이 주소만 열면 됩니다. 태블릿·휴대폰에서는 손가락으로 그려요.
  • 학생 그림은 어디에도 저장되지 않아요. 남기려면 '이미지 저장하기'를 눌러 주세요.
